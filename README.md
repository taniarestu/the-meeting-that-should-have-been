A make.fun bounty entry for
[The Meeting That Should Have Been an Email](https://make.fun/c/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9):
one line, at most 200 characters, that makes a meeting that should have
been an email funny. A judge model reads entries in pairs and keeps the
funnier line.

## The entry

> After an hour, our meeting's only decision was to book another meeting to write the email this one should have been.

The joke lands on the loop: an hour of meeting produces nothing but a
second meeting, whose job is to write the email the first one should have
been. No setup, no second sentence, and the turn arrives with the last
word.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 standard library only, no network, deterministic)
writes the single line to `/output/entry.txt`.
